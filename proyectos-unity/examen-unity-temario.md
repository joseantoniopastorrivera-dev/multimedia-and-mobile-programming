# Examen de Unity (1ª evaluación): qué entra

Lo confirmó el profe en clase el 19/11/2026.

## Formato
- **3 horas.**
- El profe da **solo las imágenes**. Tú montas el resto.
- Se entrega una carpeta con `Assets/` que contenga `Images/`, `Prefabs/`, `Scenes/` y `Scripts/`. Los *Settings* no son obligatorios.
- **Se pueden llevar apuntes:** código, fotos y guías paso a paso de la interfaz de Unity (por ejemplo, «para controlar por teclado: esto, luego aquí, arrastras con el ratón y seleccionas…»).

## Entra
| Tema | Fichas |
|---|---|
| Movimiento de objetos | 04, 05 |
| Control por teclado (Input System) | 06 |
| Colisiones y triggers | 10 |
| Creación de objetos (`Instantiate`, prefabs) | 08, 09 |
| Destrucción de objetos (`Destroy`) | 11 |
| Transform: posición, rotación y ángulos de Euler | 05 |
| Tiempo: física (`FixedUpdate`), `Time.deltaTime` y contadores de tiempo real | 12 |
| Corrutinas. Se pueden usar; el profe no exige un método concreto para el tiempo y dice que serán fáciles | 13 |

## No entra
- Interfaz de usuario (UI): botones, menús, etc.

## Consejo del profe
- **Si el objeto se mueve, ponle `Rigidbody2D`.**
